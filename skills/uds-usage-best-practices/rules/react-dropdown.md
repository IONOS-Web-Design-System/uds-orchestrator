# Dropdown (Deprecated)

> **Deprecated.** `Dropdown` has been renamed to `Selectbox` for naming
> consistency with `InputField`, `InputTextArea`, and `Combobox`. All
> `Dropdown*` aliases still work but will be removed in a future release.
>
> **Migrate:** Replace `import Dropdown from '…/dropdown'`
> with `import Selectbox from '…/selectbox'`

## Alias Mapping

| Old name            | New name             |
| ------------------- | -------------------- |
| `Dropdown`          | `Selectbox`          |
| `DropdownItem`      | `SelectboxItem`      |
| `DropdownContent`   | `SelectboxContent`   |
| `DropdownValue`     | `SelectboxValue`     |
| `DropdownSeparator` | `SelectboxSeparator` |
| `DropdownLabel`     | `SelectboxLabel`     |
| `DropdownGroup`     | `SelectboxGroup`     |
| `DropdownProps`     | `SelectboxProps`     |

See `rules/react-selectbox.md` for full usage documentation.
