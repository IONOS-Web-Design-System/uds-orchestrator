# Shared Brand Identity Principles

Source: IONOS Style Guide Version 2.2 — Brand Philosophy

These principles apply across **all 8 UDS brands**. Understanding them is what separates consistent, trustworthy design from technically-correct-but-off-brand design. Specific color values and typography differ per brand — these principles do not.

---

## Core Brand Philosophy

**Color is purposeful, not decorative.**
Every color choice should underscore the content's purpose. The IONOS palette was built for clarity and communication, not aesthetics-for-aesthetics'-sake. Ask: *does this color help the audience understand or trust the content more?*

**Consistency builds trust.**
IONOS Blue (`#003D8F`) has been the brand anchor since 1&1. Deviating from it — even slightly — erodes the implicit recognition that years of consistent application have built. When in doubt, lean into the blues.

**Restraint is a feature, not a limitation.**
The secondary palette (Amber, Purple, Green, Rose) exists precisely because it's rarely used. Its impact comes from contrast with an environment that's otherwise composed and blue. Using it freely eliminates that impact.

---

## Brand Hierarchy Principles

### 1. Primary comes first
A composition should always be anchored in the primary palette. IONOS Blue + Dark Midnight establishes trust and brand recognition. Other colors layer on top of this foundation.

### 2. Sky is directional, not decorative
Sky (`#11C7E6`) is the brand's action color — it should point somewhere: a CTA button, a key statistic, a focal element. Using it as background fill or repeated throughout a layout turns a signaling color into noise.

### 3. Secondary colors need brand context
Secondary colors (Amber, Purple, Green, Rose) only work when surrounded by a strong primary brand environment. If the blues aren't dominant, the secondary colors look random rather than IONOS. Require explicit approval before using any secondary color in a piece.

### 4. Typography hierarchy mirrors content hierarchy
Overpass is the brand's "voice" — it communicates personality. Open Sans is the brand's "words" — it communicates information. Don't use the voice typeface where you need clarity; don't use the information typeface where you need impact.

## Common Design Scenarios

### Scenario: Marketing hero / landing page header
- **Background**: IONOS Blue (`#003D8F`) or a B9→B8 gradient (`#02102B` to `#001B41`)
- **Headline**: Overpass Semibold, white text
- **Body**: Open Sans Regular, white or Cloud (`#F4F7FA`) text
- **CTA button**: Sky (`#11C7E6`) background with dark text — one button maximum in Sky per section
- **Secondary accent**: Only with approval; keep it to one color, one element

### Scenario: Product UI / dashboard
- **Background**: White or Cloud (`#F4F7FA`)
- **Text**: Dark Midnight (`#001B41`) for body, not pure black
- **Headlines**: Can be Overpass or Open Sans Semibold depending on tone
- **Interactive elements**: IONOS Blue or Sky for primary actions
- **Status indicators**: Green (G3), Amber (Y3), Rose (R3) are appropriate here because they map to semantic meaning (success, warning, error) — this is an approved use case for secondary colors

### Scenario: Illustration / creative artwork
- **Lead with the blues** — they should occupy the most visual weight
- **Sky** can be used as an energetic accent (gradients, highlights, focal shapes)
- **Secondary colors** need a narrative reason and prior approval
- **Typography** in illustrations: Overpass for titles/quotes, Open Sans for any supporting text
- **Avoid**: Arbitrary rainbow palettes, neon tones outside the defined palette, modified/tinted brand blues

### Scenario: Print collateral
- **Black text**: Use pure Black (`#000000`) for print body text (Dark Midnight is a screen color)
- **Logo backgrounds**: Use IONOS Blue (B6) or Dark Blue (B7) for light/dark logo placement respectively
- **Cool Black (C9, `#0A121C`)** is available as a deeper print black for high-quality print output

## What "Brand Awareness" Means for Secondary Color Use

The Style Guide says secondary colors only work when "the surrounding environment must guarantee high-level brand awareness." In practice this means:

- The IONOS logo is visible
- Blue tones dominate the overall composition (>60% of the color space)
- The piece would still read as IONOS if you removed the secondary color

If those conditions aren't met, drop the secondary color and solve the design problem with the primary palette.

## AA Contrast Compliance

All text/background combinations must meet WCAG 2.1 AA standards:
- Normal text (< 18px or < 14px bold): minimum **4.5:1** contrast ratio
- Large text (≥ 18px or ≥ 14px bold): minimum **3:1** contrast ratio

Key pre-approved combinations:
- White on IONOS Blue (`#003D8F`): ✓ passes AA for large text (4.07:1)
- White on Dark Blue (`#0B2A63`): ✓ passes AA (10.4:1)
- White on Dark Midnight (`#001B41`): ✓ passes AA (14.5:1)
- Dark Midnight on White: ✓ passes AAA (14.5:1)
- Dark Midnight on Cloud (`#F4F7FA`): ✓ passes AAA
- Black on Sky (`#11C7E6`): ✓ passes AA for large text — check at small sizes

Always verify IONOS Blue on white at small text sizes — it passes large text AA but not normal text AA.
