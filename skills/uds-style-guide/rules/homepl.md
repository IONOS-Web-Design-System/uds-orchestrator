# home.pl Brand

**`data-brand="homepl"` | Font: Lato | Market: Poland**

## CSS Import

```css
@import '@ionos-web-design-system/core/brands/homepl';
```

## Typography

| Role | Font | CSS Token |
|------|------|-----------|
| Headings | Lato | `--base/font/heading` |
| Body | Lato | `--base/font/body` |

Lato is a humanist sans-serif designed to feel both stable and warm. Well suited to a local market brand that values familiarity.

## Component Notes

- `CardTariff` with `underTitle` prop and `size="full"` is **only supported on the homepl brand** — do not use this combination on other brands.
